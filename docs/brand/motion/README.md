# SEDNA motion kit

Created with AI assistance (Codex).

Open index.html to preview and replay the three animations.

## Landing page use

- Arrival is the recommended hero entrance. It reveals the symbol, letters, and tagline over about three seconds, then holds.
- Orbital is an eight-second looping brand illustration. Its moving point is a decorative animation with an illustrative trajectory.
- Convergence is a presentation-style entrance that settles after about three seconds.

Use the animated SVG as an image with alt="SEDNA — Explore the Unseen." and a responsive width. The SVG includes its animation and preserves a transparent background. The HTML examples use the Void background. The static end state is shown for visitors requesting reduced motion.

For precise playback control, inline the SVG and use the Web Animations API. Pause animations when the hero leaves the viewport. Replay should be an explicit user action for the entrance variants.

MP4 and WebM exports are 1280 × 720, 30 fps, with a solid Void background and no audio. For looping video, respect reduced motion in the host page and show the static logo instead. Videos cannot automatically read the visitor's motion preference.

The animation files are branding assets for the landing page. All scientific imagery should retain its original display behavior.

The shapes and lettering come from the SEDNA brand kit. Keep the existing font licenses with the included Plex font.
