## Concept

An elongated orbit, a small reference point, and a red object at a gap in the path. The mark connects the story of 90377 Sedna with what the project lets people do: compare observations and see what changed.

Sedna was identified by its slight movement between exposures taken on November 14, 2003. The discovery was announced in March 2004. The date 14.11 can appear on commemorative artwork. The primary mark works across dates and events.

The orbit is stylized. Its 35° tilt, spacing, and dot sizes are chosen for legibility. The small point represents the Sun, the red point represents Sedna, and the gap directs attention toward the discovery.

## Choosing a logo

| Configuration | Use |
| --- | --- |
| `horizontal` | Primary logo with symbol and wordmark. |
| `horizontal-tagline` | Symbol, wordmark, and Explore the Unseen. |
| `stacked` | Stacked logo with tagline. |
| `wordmark` | SEDNA lettering only. |
| `wordmark-tagline` | Wordmark and tagline. |
| `symbol` | Full symbol. |
| `symbol-micro` | Simplified symbol at 16–24 px with the reference point omitted. |

| Suffix | Surface |
| --- | --- |
| `on-dark` | Light lettering and a red point for dark backgrounds. |
| `on-light` | Dark lettering and a red point for light backgrounds. |
| `white` | Single-color logo in pure white. |
| `black` | Single-color logo in pure black. |
| `red` | Single-color logo in Sedna red. |

Logo files have transparent backgrounds. The suffix indicates the intended surface. Artwork in `applications/` includes its own background.

## Illustrator and Photoshop

**Illustrator.** Open any SVG and ungroup it to edit the symbol and outlined lettering. Save a copy as an AI file if you need Illustrator's native format. You can also open individual pages from the vector masters PDF.

**Photoshop.** Place an SVG as a Smart Object or use a transparent PNG. To edit vector paths, open the SVG in Illustrator.

**Palette.** Import [SEDNA-Palette.ase](handoff/SEDNA-Palette.ase) into the Swatches panel. The assets use RGB. For print, convert using the ICC profile specified by your printer.

**Fonts.** Install the TTFs to typeset new text. The logo and PDF lettering is already outlined. The included Latin subsets cover English and Portuguese. See the licenses before redistributing the fonts.

## Usage guidelines

- Preserve the original angle, proportions, and spacing.
- Leave at least two red-dot diameters of clear space around the mark at its rendered scale.
- Use a configuration without the tagline when space is limited.
- Use the micro symbol at 16–24 px and the full symbol at 32 px or larger.
- Use the light variants for communication and stationery, and the Void theme in the product interface.
- Distinguish brand red from error states and colors that encode data.
- Keep brand graphics in communications artwork and preserve the astronomical observations in the viewer.
- Set the tagline exactly as **Explore the Unseen.**
